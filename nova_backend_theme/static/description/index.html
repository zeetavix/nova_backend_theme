Live in three steps

1. Install. Drop the nova_backend_theme folder in your addons path, update the apps list, install. Only dependency is web.

2. Tune. Open Settings › Appearance — pick an accent or paste your brand hex, set density, corners and column spotlight.

3. Brand. Add your brand name, contact email, login logo and favicon. The login page, tab icon and document titles follow automatically. Done.

Why teams keep it

✓ Accessible by default — visible focus rings, 44px touch targets, reduced-motion and forced-colors support.

✓ No forks, no lock-in — additive template inherits only. Uninstall and stock Odoo returns.

✓ Self-hosted type — Inter is bundled, so no request ever leaves your server for a font.

✓ Performance-first — a handful of SCSS files and two small JS modules. No frameworks, no bloat.
