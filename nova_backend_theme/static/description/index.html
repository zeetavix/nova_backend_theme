What you get

One accent, yours
Presets or a custom hex, used consistently in the backend, the portal and the login page.

White-label branding
Brand name, contact email, login logo and favicon per company — oversized uploads downscaled, dark logos plated, favicons squared.

Accessible by default

Technical

Version: 20.0.1.2.0
License: LGPL-3 (free and open source)
Price: Free
Dependencies: web only

Built for: Odoo 20 Community — no Enterprise code used or required.
Install: drop the nova_backend_theme folder in your addons path, update the apps list, install.
After install: Settings › Appearance for accent, density, corners and branding.
