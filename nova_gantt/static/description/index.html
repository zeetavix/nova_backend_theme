Nova Gantt

A modular 2D Gantt view engine for Odoo Community

Free Odoo 20.0 Community  •  By Zeetavix

Nova Gantt is a clean-room <gantt> view type for Odoo Community — the missing Enterprise-style timeline, rebuilt from scratch and usable by any model with a start/end date pair (projects, events, leaves, manufacturing orders). Define lanes, a date range and a measure in XML; the engine renders an editable timeline with drag-to-move, edge resize, sticky lanes and hero-number KPIs.

Any lanes, any period

Section + row grouping, month and quarter ranges with prev/today/next navigation, weekend toggle, sticky lane headers and a today line.

Drag to reschedule

Grab a bar to move it, drag its edges to resize — snapped to days, written back through a guarded server API. Keyboard works too: arrows move, Shift+arrows resize, Enter opens the record.

Build your own Gantt in minutes

<gantt string="Portfolio" date_start="date_start" date_stop="date"
      editable="1" kpi_unit="d">
    <field name="user_id" type="row" section="1" string="Manager"/>
    <field name="name" type="row" string="Project"/>
</gantt>

Server API (on every model, via base)

  • nova_gantt_fetch — one-RPC record fetch with normalised relation values
  • nova_gantt_update_dates — guarded move/resize write with stop clamped at start
