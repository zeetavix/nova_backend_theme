Nova Grid

A modular 2D grid view engine for Odoo Community

Free Odoo 20.0 Community  •  By Zeetavix

Nova Grid is a clean-room <grid> view type for Odoo Community — the missing Enterprise-style grid, rebuilt from scratch and usable by any model (timesheets, attendance, sales, stock). Define rows, a date/selection/many2one column and a measure in XML; the engine renders an editable matrix with totals, heatmap, keyboard navigation, copy-previous-period and CSV export.

Any rows, any period

Section + row grouping, week and month ranges with prev/today/next navigation, weekend toggle, sticky first column and sticky totals.

Sections with avatar chips and collapse

Group by any many2one (employee, project, …). Section bands carry avatar chips, line counts and an accent edge — click to collapse. Titles can never render blank, copy-previous seeding is pure (no junk rows) and CSV export neutralises formula injection.

Build your own grid in minutes

<grid string="My Grid" editable="1" show_heatmap="1"
      kpi_capacity_target="40" kpi_unit="h" overtime_at="8">
    <field name="employee_id" type="row" section="1"/>
    <field name="project_id" type="row"/>
    <field name="date" type="col">
        <range name="week" string="Week" span="week" step="day" default="1"/>
        <range name="month" string="Month" span="month" step="day"/>
    </field>
    <field name="unit_amount" type="measure" operator="sum"/>
</grid>

Server API (on every model, via base)

  • nova_grid_fetch — one-RPC matrix fetch (ORM-version-proof read_group wrapper)
  • nova_grid_update_cell — cell deltas with create-on-empty + placeholder cleanup
  • nova_grid_unavailability — hook for greyed columns (leaves, holidays)
  • nova_grid_copy_previous — previous-period row skeletons, pure (no writes)
